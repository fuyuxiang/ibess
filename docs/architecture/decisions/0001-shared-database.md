# ADR-0001：保留共享数据库，统一迁移所有权

状态：已实施。

项目已有业务、识别、告警和证据保全通过同一 PostgreSQL 协作。直接改成每服务独立数据库会同时影响阶段快照、授权核验、事件状态和录像保全。本次保留数据位置、表名、HTTP 地址、Redis 流名和证据路径，先建立单一 DDL 负责人及公共数据契约。

API 负责数据库迁移。公共事件、证据、算子及风险线索映射放入可安装包，由消费者复用。消费者代码不再建表；其他业务表仍由 API 管理，消费者通过现有读模型访问。`ownership.json` 声明允许的写入者，架构测试检查覆盖范围。

这个选择允许分阶段改造，同时维持现有功能。代价是共享表仍造成发布耦合，后续字段修改必须评估所有读写服务；当前代码约束不代替数据库账号权限隔离。未来确需分库时，应先引入稳定的快照读取接口或配置事件，再独立迁移数据。
