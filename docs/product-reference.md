## 衡鉴的产品定位

名称为 **衡鉴 HengJian**，副标题为 **智能评标现场监管平台**。衡表示客观衡量，鉴表示以证据核查；名称服务于现场监管和人工复核的产品职责。代码仓库、包名及既有部署标识继续使用 `ibess` / `poc`，避免品牌调整影响现有环境。

界面首先帮助值守人员回答：当前在监管哪一场、哪里需要关注、下一步该处理什么。项目资料、人员授权、设备区域、规则参数和账号权限集中在管理中心。入口显示和服务端角色权限需要保持一致，隐藏按钮不能替代接口鉴权。

## 信息组织原则

1. **以场次组织工作。** 评前准备、现场值守、异常处理和收尾归档围绕同一场次衔接，避免人员在多个工具中自行拼凑上下文。
2. **突出下一步动作。** 每页优先呈现当前任务与主要操作，诊断细节、历史记录及高级参数放入相应页面或次级区域。
3. **把业务状态与技术状态分开。** 有待核查事件、录像缺口、模型未配置是不同问题，分别显示事实和处理入口。
4. **让证据支撑判断。** 告警进入核查和处置流程；机器置信度不能替代违规认定，截图和回放时间必须对应原始采集记录。
5. **README 说明真实能力。** 产品截图来自本项目页面；合成预览要标注，未接通现场设备不能写成现场实测，不展示虚构准确率、部署案例或许可证。

## 本轮功能落点

业务入口为 `/sessions` 和 `/sessions/:id`，配置入口为 `/admin` 和 `/admin/sessions`。场次作业使用 `/api/supervision/workflows`，与通用资料、规则参数配置分开。新增评前人工检查、配置与授权检查、阶段方案推进、巡查交接、现场结束、最终归档和资料变化后的补充归档提示。

草稿不要求已获得运行中的识别心跳；配置检查与运行核验分开。保存阶段方案不等于消费者已应用，页面分别显示真实回执状态。结束现场不会直接把待办事件认定为已完成；未办结事件会阻断最终归档，媒体缺口需要保留事实与说明。

产品截图及场次操作以本轮实际实现和验收结果为准。参考项目的社区规模不构成衡鉴自身成熟度或现场识别效果的证明。

## 值守界面的进一步调整

日常入口改为视频值守台：机位资源树、监控画面、持续告警队列同屏显示。欢迎语、统计卡片与快捷入口移出值守首页；场次准备、台账、档案和管理中心继续独立使用。支持 1 / 4 / 9 分屏和全屏值守；浏览器限制原生全屏时切换窗口内全屏。

点击告警按场次及机位别名唯一匹配来源，中心切换到事件证据。录像同时读取已有事件保全接口与证据对象，使用原鉴权播放地址；录像、关键帧和原音分别显示，核查操作沿用既有版本检查、岗位权限与留痕。

## 产品减法的实际落点

主导航仅保留实时监控、告警处置、监管档案、场次管理。此次收减按依赖逐项处理：

| 收减项 | 现在从哪里办理 | 保留的后台依赖 |
| --- | --- | --- |
| 撤去独立历史视频审计页 | 日常核查使用告警证据，历史资料通过档案查阅 | 离线任务、审计结果与视频接口 |
| 撤去高级阶段控制台 | 单场准备维护方案，业务工作区推进阶段 | 阶段快照、控制流、消费者范围和应用回执 |
| 撤去独立人脸工作台及外链生成入口 | 场次准备中按需启用身份核查，再从人员行管理照片与核验 | 登记照、身份结果、既有限时核验链接与公共核验页 |
| 撤去独立音频工具入口 | 事件补证按需展开；管理员可做低频维护 | 拾音接入、转写、语义任务、原音与显式业务绑定 |
| 合并人员授权操作 | 人员资料收进场次准备；基础监管可不填名单，身份核查按需启用 | 原事实、核验关联和授权版本；一次事务保存 |
| 收减快照和导出操作 | 档案默认正式归档，保留报告与证据包导出 | 历史查阅记录、JSON 接口、导出鉴权与留痕 |
| 撤去重复管理概览并收起次要字段 | 管理中心直接进入现场配置；项目、场地与监测合并组织 | 基础资料 CRUD、必填约束、项目成员关系和消费者接入配置 |

旧工具地址提供兼容跳转，保留原访问限制及场次范围。删除退出产品流程的页面、样式和旧阶段页浏览器桩脚本；公共 API、模型、媒体服务和仍有测试依赖的契约组件继续保留。人员独立菜单进一步撤去，管理中心只保留现场配置、识别规则、运行保障及账号权限。

名单接口复用原有事实与授权表；`0005_optional_identity` 仅为场次增加显式身份核查选项。默认开场不依赖名单或人脸核验；启用时才校验相关准备，身份未知不认定为未授权。关闭选项不删除原照片、核验或授权历史。已开始场次保留旧模式，避免升级过程中改变识别依据。


## 场次准备与管理中心的进一步收减

| 减法 | 当前落点 |
| --- | --- |
| 合并场次创建与准备 | 业务场次列表创建，直接进入本场准备；管理中心维护固定资源 |
| 复用机位与区域 | 评标室资源只追加版本，场次复制明确版本，后续修订不覆盖旧场次 |
| 默认监测方案 | 基础与完整方案按名称选择，保存并应用同事务；旧矩阵接口和快照保留 |
| 按需标定 | 基础方案可无工位区、无门线开场，对应能力启用后才要求标定 |
| 撤去业务部署导出 | 本机 CLI 从 API 容器读取本场准确多通道范围，保留原 scope-file 用法 |
| 收起规则技术内容 | 列表聚焦名称、风险与启停，版本自动生成，技术详情及留痕按需展开 |
| 收减资料表单 | 业主、日期、位置、模式收进补充资料；缺省不伪造业主或位置 |
| 故障优先与维护下沉 | 默认显示异常及待核验，无拾音时隐藏语音列；模型与部署维护按需进入 |

资源版本由数据库保护，不允许 UPDATE / DELETE；每场准备、方案切换、区域载入和归档均保留对应历史。后台识别、告警、媒体、规则、授权、部署和历史查阅接口继续提供给现有依赖。
