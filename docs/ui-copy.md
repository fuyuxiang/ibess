# 界面文案规范与逐页检查

本轮检查覆盖 14 个页面文件、登录页及相关弹窗，修改导航、标题、状态、操作按钮、表单帮助、空状态和错误提示。首轮按语法节点处理 537 处文案，随后核对状态含义和实际显示；不替换用户填写的说明、识别原文或历史业务记录。

## 企业级产品参考

- [大华 DSS Professional V8.7 官方产品资料](https://software.dahuasecurity.com/DSSDesignTool/static/media/DSS%20Pro%208.7.0_Datasheet.ff06d565.pdf)：参考企业安防平台对实时监控、录像回放、事件管理和运行维护的任务划分与命名。
- [Elastic Cases 官方文档](https://www.elastic.co/docs/explore-analyze/cases)：参考告警、证据和处置记录集中查阅的表达。
- [Ant Design 文案规范](https://5x.ant.design/docs/spec/copywriting-cn/)与[按钮规范](https://ant.design/docs/spec/buttons-cn/)：采用统一术语、用户视角、明确动作和可执行的错误提示。

以上用于确定产品用语与表达方式，不移植其他产品的功能承诺。

## 统一术语

| 对象 | 使用方式 |
| --- | --- |
| 告警 | 系统发现或人工标记的待核查事件；具体观察内容称“线索”，人工确认后形成“结论” |
| 事件 | 用于事件编号、事件详情及全流程记录，不将所有事件直接称为违规 |
| 处理状态 | 待核查、补充核查中、待分派、待反馈、待复核、已归档；状态代码保持原值 |
| 监测通道 | 视频机位和拾音通道的统称；仅指视频画面时使用“机位” |
| 身份核查 | 场次中的名单、身份依据与授权核查；照片一对一比对称“身份核验” |
| 待核验 | 缺少有效检测记录或证据时使用，不显示为正常、就绪或已完成 |
| 证据保全 | 仅在实际保全完成时显示“已保全”；存在缺口时说明缺失情况和下一步操作 |
| 操作记录、变更记录 | 分别记录业务办理与配置修改；技术细节保留在对应详情中 |

## 写法

1. 页面标题与导航名称一致，副标题用一句话说明当前任务。
2. 按钮使用明确动词，如“新建场次”“开始监管”“确认归档”“撤销关联”。
3. 空状态说明缺少什么，以及如何继续；错误提示提供刷新、重试或联系管理员等下一步。
4. 必填项使用简短校验信息；选填资料统一标注“选填”。文件格式、大小、时间范围和次数限制按实际能力保留。
5. 删除、重新核查、归档、照片替换、密码变更等操作保留实际影响说明。
6. 核验相似度、活体检测限制、录像覆盖和资料缺失属于判断依据，精简时保留原意。
7. 日常页面使用业务用语；服务接入、模型参数等技术内容集中在运维设置或技术详情。
8. 后台状态代码、权限、请求参数与历史快照不随展示文案改名。

## 逐页落点

| 页面 | 本轮调整 |
| --- | --- |
| 登录与登录状态 | 使用“登录衡鉴”，缩短品牌说明、账号引导和登录异常提示 |
| 实时监控 | 统一标题、告警状态与来源，简化视频连接失败和空画面提示 |
| 告警处置 | 统一“告警、处理状态、待核查”等用语，缩短检索和筛选说明 |
| 事件详情 | 精简证据与核查提示；区分识别风险和人工结论，明确补证、撤销与归档动作 |
| 监管档案 | 使用“场次报告”，简化覆盖说明；保持历史记录、资源版本及缺口信息 |
| 场次管理 | 简化列表说明与新建场次引导，统计范围明确为全部场次 |
| 单场工作区 | 简化开始、结束、巡查、许可和归档按钮；准备说明按场次状态展示 |
| 现场配置 | 用一句话说明机位、区域及场次复用关系 |
| 现场资源 | 统一“通道、主机位、出入口线、资源版本”，明确复制和更新的影响 |
| 项目与场地 | 移除表单中的实现术语，明确关联、工位分配和删除限制 |
| 识别规则 | 标题与导航一致，应用与识别状态使用中文标签，技术内容称“变更记录、适用范围” |
| 运行保障 | 明确视频、录像与分析状态，缩短异常、待核验和空列表说明 |
| 运维设置 | 简化服务接入步骤，说明身份参数作用范围及阈值校准要求 |
| 账号权限 | 统一管理员、监管人员、处置人员和只读人员称谓，简化岗位与账号状态说明 |
| 人员身份核验 | 简化链接、拍照和上传引导，保留次数、失效、活体检测及人工复核提示 |

共享弹窗和组件一并检查：人员资料、名单历史、照片登记与核验、限时核验链接、录音转写、录音风险分析、现场原音、区域标定、人工标记、证据补充、任务接收、账号菜单及异常边界。

## 修改示例

| 修改前 | 修改后 |
| --- | --- |
| 操作成功，已保存到后端 | 已保存 |
| 登记现场结束 | 结束监管 |
| 确认并留存记录 | 按操作显示“确认归档”“结束监管”“确认推进”或“保存记录” |
| 待确认 / 待登记处置 / 待处置反馈 | 待核查 / 待分派 / 待反馈 |
| 文件音频转写与说话人分段 | 录音转写 |
| 幂等去重 | 已合并重复任务 |
| 判定本人阈值 | 匹配通过阈值 |
| 手机未寄存 | 入口携带手机 |
| 当前以查阅方式展示 | 当前为只读状态 |
| 技术详情与配置留痕 | 技术详情与变更记录 |

历史报告中的旧版固定覆盖说明只在展示与导出时映射为简洁文案，原快照保持不变；其他自定义说明原样显示。保全未完成时只展示实际片段数量及原因，不使用“已独立保存”等完成措辞。

## 验证

- 前端测试 53 项通过；TypeScript 与生产构建通过。
- 场次准备、场次流程、告警处置、证据和工作区接口回归 58 项通过，0 跳过。
- Ruff 与差异空白检查通过。
- 使用本机隔离预览及合成资料，逐页检查主页面与重点弹窗；检查无录像、无录音、模型未就绪、历史报告、核验链接缺失等状态。
- 页面检查未提交业务认定、资料删除、身份参数或账号权限变更。未新增数据库迁移。
