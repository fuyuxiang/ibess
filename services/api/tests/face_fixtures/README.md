# 仅供自动化测试的公开样例

这些图片仅用于隔离测试，不登记进正式人员库。

- `astronaut.png`：NASA 宇航员 Eileen Collins 照片，NASA 公共领域样例，经 scikit-image v0.25.2 分发。
  来源：https://github.com/scikit-image/scikit-image/blob/v0.25.2/skimage/data/astronaut.png
  数据说明：https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut
- `grace_hopper.jpg`：美国海军 Grace Hopper 公共领域照片，经 Matplotlib v3.10.7 示例库分发。
  来源：https://github.com/matplotlib/matplotlib/blob/v3.10.7/lib/matplotlib/mpl-data/sample_data/grace_hopper.jpg
  数据说明：https://matplotlib.org/stable/gallery/images_contours_and_fields/image_demo.html

“同人”测试用同一照片旋转、调暗的版本；不等同于现场跨时间、跨摄像头实测。
